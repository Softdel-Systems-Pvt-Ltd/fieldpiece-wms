# Fonts

Put licensed Myriad Pro files here (`MyriadPro-Regular.woff2`, `MyriadPro-Semibold.woff2`, `MyriadPro-Bold.woff2`)
once the licence is confirmed (Section 3.3). Font binaries are git-ignored by default. Remove the ignore rule only if
the licence allows committing them.

Until then the app uses the fallback stack in `src/styles/tokens.css` and loads **Source Sans 3** and
**JetBrains Mono** from Google Fonts in `index.html`.
